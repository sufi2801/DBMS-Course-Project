## Project Title

Design and Implementation of a Database Management System for Crop Planning and Farm Input Management System

## Project Description

A relational database management system designed to support crop planning and farm input management for small-to-medium farms.

## Technologies Used

- MySQL
- Python
- Streamlit

## Main Features

- Farm record viewing
- Farm record insertion
- Farm record deletion
- Crop planning
- Farm input management
- Irrigation and labour tracking
- Harvest and sales management
- SQL queries and aggregations
- Database constraints and triggers
- Crop profitability analysis
